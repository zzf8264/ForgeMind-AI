# Roadmap

## Current

- Next.js enterprise console
- FastAPI control plane
- Redis-backed task dispatch model
- Qdrant repository context storage
- Example multi-agent classes
- Prometheus and Grafana bootstrap

## Near Term

- Real worker process with Redis queue consumers
- GitHub App installation flow
- Sandbox runner with filesystem and network policy
- OpenTelemetry traces and structured audit events
- Model provider adapters and failover routing

## Enterprise

- SSO, SCIM, and role based access control
- Approval workflows for production write actions
- Tenant-level token budgets and chargeback exports
- Policy engine for repository access and data residency
- Multi-region active-active deployments
